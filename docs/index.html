Core Guarantees

Three Promises No Existing Simulator Makes

Most open-source simulation environments fail defense research on at least one critical axis. LOITER-SIM is designed to succeed on all three simultaneously.

🔐

Bitwise-Deterministic Execution

Identical (scenario, seed) → identical bit-for-bit output. Every run. Any IEEE 754-compliant machine. Reproducible bugs. Reproducible research.

⚡

1000× Real-Time Headless Throughput

50,000 agents at 50 Hz on consumer hardware. Gymnasium-compatible Python API for RL at industrial training scale, not toy-environment scale.

📐

Physics-Grade, Cited Specifications

Every model traced to primary literature. No ad-hoc approximations. RCS-based radar. ISA atmosphere. 6-DOF RK4 dynamics. Verifiable before a line of code runs.

Licensing

Open by Default · Commercial When You Need It

LOITER-SIM uses a dual-license model — the same approach used by MySQL, Qt, and MariaDB. The Community Edition is fully open under GPL v3. The Commercial Edition is available for organizations that cannot comply with the GPL's copyleft provisions (proprietary, classified, or export-controlled deployments).

Edition License Max Agents Key Extras
Community GPL v3 Up to 500 Full engine · Basic sensors · RL API · Open-source modifications required
Commercial Proprietary Unlimited Advanced threat models · GPU acceleration · DIS/HLA · Classified deployment · No copyleft obligation

Commercial licensing inquiries: open a GitHub Issue tagged commercial-licensing.
