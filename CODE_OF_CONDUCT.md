# Code of Conduct

## Our Commitment

LOITER-SIM is a professional-grade engineering project. Contributors are expected to maintain a working environment that is technically rigorous, intellectually honest, and respectful — regardless of background, experience level, or affiliation.

This project attracts contributors from academia, the defence industry, and the broader open-source engineering community. All participants are expected to uphold the standards of professional scientific and engineering discourse.

---

## Standards

### Expected Behavior

- **Technical rigor.** Claims about physics, numerics, or performance must be backed by evidence: citations, benchmarks, or reproducible experiments.
- **Constructive criticism.** Critique ideas, not people. Technical disagreements should be resolved with data and argument, not authority or volume.
- **Intellectual honesty.** Acknowledge uncertainty, flag assumptions, and update your position when presented with contrary evidence.
- **Respect for expertise.** This project spans multiple disciplines. Treat contributors with deep domain knowledge — whether in aerodynamics, control theory, or software engineering — with appropriate deference in their area of expertise.
- **Professional communication.** Written communication is permanent and public. Write as if your employer, clients, or academic advisor can read it — because they can.

### Unacceptable Behavior

- Personal attacks, insults, or harassment of any kind
- Dismissing contributions based on the contributor's affiliation, nationality, or credentials rather than the merits of the work
- Misrepresenting others' words or positions
- Publishing others' private information without consent
- Sustained off-topic discussion that derails technical threads
- Bad-faith contributions (introducing deliberate bugs, vandalism, spam)

---

## Enforcement

### Reporting

Violations of this Code of Conduct can be reported by:

1. Opening a **private** GitHub issue (if GitHub supports private issues in this repository's plan), or
2. Contacting the maintainer directly via the contact method on the maintainer's GitHub profile.

Reports will be reviewed within 5 business days. The identity of the reporter will be kept confidential.

### Consequences

| Severity | Example | Response |
|----------|---------|----------|
| Minor | Single off-color comment | Private warning |
| Moderate | Repeated unprofessional behavior | Public warning, temporary contribution ban |
| Severe | Harassment, deliberate sabotage | Permanent ban from the project |

The maintainer's decisions on enforcement are final. Appeals may be submitted in writing.

---

## Scope

This Code of Conduct applies to all project spaces: GitHub issues, pull requests, discussions, commit messages, documentation, and any other forum directly associated with LOITER-SIM. It also applies when an individual is representing the project in public spaces.
